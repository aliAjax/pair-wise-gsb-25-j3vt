## 试戴评估与处方签发闭环

- **试戴占用**：每次试戴占用一套试戴片；同一时段同一试戴片不得重复占用，冲突时拦截并记录
- **按眼评估**：按左右眼分别记录矫正视力、适应时间、不适症状与试戴参数（球镜/柱镜/轴位）
- **低视力原因**：任一眼矫正视力未达 0.8 必须填写原因；原因未填不得签发，也不能释放占用
- **签发冻结**：签发后处方冻结，复诊调整只能新建带原因版本，旧版本保留在修订链中
- **持久一致**：记录、占用、签发与修订链持久化在 localStorage，刷新后保持一致
- **冲突面板**：冲突时列出患者、试戴片、时段和触发规则（占用冲突 / 低视力原因缺失 / 冻结处方直改）

## 页面结构

- 指标看板：今日试戴、占用中试戴片、已签发处方、待补低视力原因
- 新建试戴：患者 / 试戴片 / 日期时段选择，占用冲突实时提示
- 试戴评估：占用中的试戴卡片，按左右眼录入评估并执行释放或签发
- 处方签发与修订链：冻结处方 + 历史版本 + 带原因的复诊调整
- 冲突与触发规则：全部规则拦截事件留痕
- 全部试戴记录：占用中 / 已释放 / 已签发全量记录，可一键重置演示数据
