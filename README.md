# hxwl-11 眼科验光记录

试戴评估 → 试戴片占用管控 → 处方签发 → 冻结与复诊修订的完整闭环。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5111

## 闭环流程

1. **新建试戴**：选择患者与试戴片、日期时段，按左右眼录入矫正视力、适应时间、不适症状与瞳距；提交即占用该套试戴片。
2. **占用管控**：同一时段同一试戴片不得重复占用（R1），同一患者同一时段不得重复试戴（R2）；冲突会被拦截并列入冲突记录，逐条展示患者、试戴片、时段与触发规则。
3. **低视力原因**：任一眼矫正视力未达 0.8 必须填写原因（R3）；原因未填不得签发处方，也不得释放占用。
4. **签发冻结**：签发后处方冻结（R4），试戴片自动释放；复诊调整只能新建带原因版本，完整修订链留痕。
5. **刷新一致**：记录、占用、签发与修订链持久化于 localStorage，刷新后状态一致；侧栏可一键重置演示数据。

## 页面结构

- 指标看板：试戴占用中 / 待补原因 / 已签发处方 / 冲突拦截
- 侧栏：试戴片库存（空闲/占用）、闭环规则、冲突记录
- 主区：新建试戴记录表单、试戴记录（原因补填、释放、签发）、已签发处方（修订链、复诊调整）
